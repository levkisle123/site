# МК Мебель

Статический демонстрационный сайт мебельного магазина.

## Просмотр

Для локального просмотра: `python3 -m http.server 8000` из корня репозитория. Сборка и установка зависимостей не нужны.

## GitHub Pages

В Settings → Pages → Build and deployment выберите Deploy from a branch, ветку main, папку / (root), затем Save.

Планируемый адрес после успешной публикации: https://levkisle123.github.io/site/

Файлы сайта находятся в корне. `.nojekyll` отключает ненужную обработку Jekyll. Все изображения и шрифты локальные. Относительные ссылки поддерживают публикацию в /site/.

Для следующих обновлений изменяйте опубликованные HTML/CSS/JS и ресурсы в репозитории. Замена только ZIP не обновляет Pages. `mkmebel-v4.zip` — отдельная скачиваемая копия сайта.

Каталог и изображения демонстрационные. Выбранные товары переносятся в сообщение на странице контактов. Пользователь копирует текст и отправляет его в Instagram @mkmebelvdom. Серверная отправка и онлайн-оплата не подключены. Подробности проверок — в QA.md.
